Some teams simply can’t use a cloud tool, no matter how good it is. If you’re running an air-gapped or restricted network — government, defense, critical infrastructure — a normal SaaS feedback platform is a non-starter before you even get to features.

**FeedbackPro Private Server** was built for exactly that gap: a fully on-premise, air-gapped deployment of FeedbackPro that never has to touch the outside internet.

## What You Get, Fully Internal

-   Survey creation and distribution inside your own network

-   All feedback data stored on-premise, under your control

-   Core feedback collection and reporting — the tools you actually rely on day to day

## Why Teams Choose This Over Cloud

-   **Built for isolated networks.** No workaround needed to fit your existing security policy.

-   **You keep full control of the data.** Everything stays internal, which makes meeting strict compliance requirements a lot more straightforward.

-   **It doesn’t care if you’re offline.** Field sites, secure facilities, remote operations — feedback collection keeps running with or without connectivity.

## Worth Knowing Before You Deploy

To keep the security boundary airtight, Private Server intentionally leaves out two cloud-dependent features: **staff module management** and **email alerts**. Everything else — survey distribution, response collection, centralized reporting — works exactly as you’d expect. A few tips for running it well:

-   Set internal access roles before you deploy, not after.

-   Lean on structured surveys over ad-hoc feedback for cleaner data.

-   Build a manual reporting cadence, since automated email alerts aren’t part of this version.

## Who It’s For

Government departments gathering internal or citizen feedback, defense teams handling sensitive operational input, remote industrial sites without reliable connectivity, and enterprise security teams that simply aren’t allowed to run external SaaS tools.

## Tl;dr:

FeedbackPro Private Server brings core feedback collection fully on-premise and air-gapped — no internet required, all data stored internally. Staff module and email alerts aren’t included, but everything else works exactly as it does in the cloud version.
